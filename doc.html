Документация: ΔОS-Οлимп

Общее описание

ΔОS-Οлимп — текстовая игра с выбором, оформленная в стиле античного интерфейса. Игрок исследует мир, переходя между сценами по выделенным словам.

Игра имеет систему сохранений, вывод текста с эффектом печати и возможность загрузки внешнего JSON с описанием сцен.

Основные возможности

  • Стартовое меню: новая игра, загрузка, помощь, выход.
  • Типографика: текст выводится постепенно, с возможностью пропустить.
  • Выборы: слова с классом choice переходят к новым сценам.
  • Сохранение: 6 слотов, имена по дате и времени.
  • Загрузка: из главного меню или в процессе игры.
  • Подтверждение: перед сохранением или загрузкой.
  • Локальное хранилище: все данные сохраняются в localStorage.

Ключевые функции

appendScene(id)
Выводит сцену по ключу id из объекта P.
typeWrite(html, container, done)
Постепенно выводит html в контейнер. При клике — сразу весь текст.
renderMainMenu()
Отображает стартовое меню игры.
startGame()
Запускает игру, показывает первую сцену.
openSlotMenu(mode, fromMain)
Открывает меню сохранения/загрузки. mode: 'save' или 'load'.
renderConfirmMenu(mode, slot)
Показывает окно подтверждения действия с указанным слотом.
confirmSave(slot)
Сохраняет текущую сцену в слот slot.
confirmLoad(slot)
Загружает сцену из слота slot и переходит к ней.
cancelSlotMenu()
Возвращает из меню сохранений/загрузок в игру или в главное меню.

Структура сцен (P)

Объект P содержит все сцены. Каждая сцена — объект с ключом html:

{
  "start": {
    "html": "Я стою перед входом…"
  }
}

Заметки

  • Игра не требует серверной части, работает в браузере или в сборке Tauri.
  • Не используется внешнее CSS, только базовые классы.
  • Сценарий можно расширять без изменений в логике, редактируя JSON или объект P.
